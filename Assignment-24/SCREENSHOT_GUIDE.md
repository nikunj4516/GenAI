# Task 1, step 6 – LangSmith screenshot (for the Drive upload)

The screenshot has to come from **your own LangSmith account**, so it cannot be generated by the code.
Take it right after a successful run of Task 1 with `LANGSMITH_API_KEY` set in `.env`.

## 1. Run Task 1

```bash
ollama pull llama3                      # once
python PART1_Getting_Started/task1_ollama_setup_chat.py
```

The output must show `LangSmith tracking ... ON` and a `Traces sent to LangSmith` block with a **Run id**.

## 2. Open the trace

1. Go to <https://smith.langchain.com> and sign in.
2. Left menu → **Tracing** (Tracing Projects) → project **`genai-assignment-24-ollama-chatbot`**.
3. Click the run **`task1_ollama_basic_chat`** (it has two child runs: `OllamaLLM` and `ChatOllama`).

## 3. Capture "all necessary details"

Take one screenshot of the trace page (or two: the project list and the trace) that shows:

| What | Where |
|---|---|
| Project name | top of the page / breadcrumb |
| Run name and status (Success) | trace header |
| Input prompt and output text | right panel, *Input* / *Output* |
| The child runs `OllamaLLM` and `ChatOllama` (the model calls) | left tree |
| Latency and (for ChatOllama) token counts | trace header / run details |
| Model name (`llama3`) and tags `assignment-24`, `task-1`, `ollama` | *Metadata* / tags |
| Start time / date | run list |

Save the image(s) in the `screenshots/` folder and upload them to the Drive folder.

## If no trace appears

- `LANGSMITH_API_KEY` missing or wrong → the script prints `LangSmith tracking ... OFF`.
- EU account → add `LANGSMITH_ENDPOINT=https://eu.api.smith.langchain.com` to `.env`.
- Wrong workspace/project selected in the web app → pick the project name printed by the script.
